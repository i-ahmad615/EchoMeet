FAQ

Answers to common questions

Quick guidance to help you adopt EchoMeet with confidence.

Is EchoMeet free to use?

Yes. You can create an account and use the core communication flows in the current release.

Do I need to install any app?

No installation is required. EchoMeet runs in modern browsers with camera and microphone permissions.

How do friend requests work?

Send a request from Dashboard search. The other user can accept/reject, and both dashboards reflect the state after refresh.

Can I use EchoMeet for accessibility-focused sessions?

Yes. The platform includes voice/text conversion, sign-oriented workflows, and AI assistance designed for inclusive communication.

Where can I report issues?

Use the Contact page or email support@echomeet.app with steps to reproduce and browser details.
